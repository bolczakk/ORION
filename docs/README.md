# DOKUMENTACJA

W tym folderze znajdują się wszystkie materiały pomocne w realizacji projektu, instrukcje, schematy, zdjęcia.

---

### 📑 Zawartość folderu

* **Instrukcje:** Opis uruchomienia robota krok po kroku.
